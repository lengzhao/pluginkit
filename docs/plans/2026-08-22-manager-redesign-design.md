## 决策

| 决策 | 选择 |
|---|---|
| 产品形态 | 同一工作台；空白新建与导入 YAML 都是入口 |
| 主交互 | 填槽装配，不是画布，也不是 YAML 编辑器 |
| 共享实例 | 操作为主：内联节点可「提取为共享」；无常驻共享区 |
| 右栏 | 检查器为主；YAML 仅导入/导出与只读预览 |
| 校验 | 每次编辑自动跑 structure + plan；试装配才跑 Build |
| 前后端分工 | 无会话编辑命令：`document + op → document + view + diagnostics` |

## 明确不做

- 画布拖拽布局
- YAML 双向绑定
- 切视图（树状/扁平）以及切视图改数据
- 常驻插件目录侧栏、常驻共享实例侧栏
- 运行时加载未编译插件
- 服务端会话与持久化
